# 05. Карта

`components/planner/TripMap.tsx`. Библиотека — **MapLibre GL** (открытый
форк Mapbox GL): векторная карта на WebGL. Подложка — бесплатные тайлы
**OpenFreeMap**: стиль `positron` для светлой темы, `dark` — для тёмной.

## React и императивная карта

Карта — объект со своим состоянием, React её не рендерит. Поэтому:

1. Карта создаётся **один раз** в `useEffect(() => …, [])` и лежит в `useRef`.
2. Остальные эффекты **синхронизируют** её с пропсами: поменялась поездка —
   обновили данные линий; выбрали день — передвинули камеру.
3. В очистке эффекта — `map.remove()`, иначе при уходе со страницы
   останется WebGL-контекст.

Колбэки (`onHighlight`) нужны в обработчиках, которые навешиваются один раз
при создании метки. Чтобы они не устарели, последние версии лежат в
`handlers.current`.

## Слои

| Что | Как |
| --- | --- |
| Линии всех дней | GeoJSON-источник `routes`, слой с `line-color: ['get', 'color']` |
| Белая «подложка» под линией | тот же источник, слой потолще под основным |
| Маршрут выбранного дня | источник `active-route` с `lineMetrics: true` |
| Метки | HTML-элементы `Marker` (кнопки с номером) |

Метки — HTML, а не слой WebGL: их легко стилизовать CSS, у них есть
hover/focus и они доступны с клавиатуры. Мест в поездке десятки, на
производительность это не влияет.

Тонкость: MapLibre двигает метку через `transform` и меняет её `opacity`.
Если масштабировать сам элемент через CSS `scale`, вместе с ним
масштабируется и смещение — метка «уезжает». Поэтому всё оформление — у
вложенного `<span>`.

## Анимация маршрута

При выборе дня линия «рисуется» от первой точки к последней:

```ts
map.setPaintProperty('active-route', 'line-gradient',
  ['step', ['line-progress'], color, t, 'rgba(0,0,0,0)'])
```

`line-progress` — положение вдоль линии от 0 до 1 (доступно только при
`lineMetrics: true`). До `t` линия цветная, после — прозрачная. `t`
растёт от 0 до 1 в `requestAnimationFrame` с замедлением в конце.
Одновременно `fitBounds` перелетает камерой к точкам дня.

## Смена темы

`map.setStyle()` заменяет всё содержимое карты, включая наши слои. Поэтому
слои добавляются в обработчике `style.load` — он срабатывает и при первой
загрузке, и после каждой смены стиля. Счётчик `ready` заставляет эффекты
заново залить данные в новые источники.

## Воркер

MapLibre 6 разбирает тайлы в Web Worker'е — отдельном файле, адрес которого
библиотека вычисляет во время работы. Сборщик Next такой адрес не видит и
файл не копирует, поэтому `scripts/copy-maplibre-worker.mjs` перед `dev` и
`build` кладёт воркер в `public/maplibre/`, а в коде стоит
`setWorkerUrl(…)`.
