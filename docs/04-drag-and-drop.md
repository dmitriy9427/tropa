# 04. Перетаскивание

Библиотека — `@dnd-kit` (`core` + `sortable`). Код — `components/planner/Board.tsx`
и `PlaceCard.tsx`.

## Устройство

```
<DndContext>                      общий «контекст» перетаскивания
  <Column id="ideas">             useDroppable — сюда можно бросить
    <SortableContext items=[…]>   список с сортировкой
      <SortablePlace/>            useSortable — карточку можно тащить
  <Column id="day:abc">
    <SortableContext …>
  …
<DragOverlay>                     копия карточки, которая едет за курсором
```

`Column` нужен для пустых дней: в пустом `SortableContext` нет карточек,
над которыми можно оказаться, поэтому сам список регистрируется как
`droppable` с id `day:…`.

## Три события

- **onDragOver** — карточку тащат над **другим** списком. Сразу переносим
  её туда (`movePlace`), чтобы соседние карточки раздвинулись. Позиция:
  индекс карточки под курсором, +1 если курсор ниже её середины.
- **onDragEnd** — отпустили. Если внутри одного списка — фиксируем новый
  порядок.
- **onDragCancel** — Esc. Перед началом перетаскивания запомнили поездку
  (`snapshot`), теперь возвращаем её — отменяются и промежуточные переносы
  из `onDragOver`.

## Датчики (sensors)

```ts
useSensor(MouseSensor, { activationConstraint: { distance: 6 } })
useSensor(TouchSensor, { activationConstraint: { delay: 200, tolerance: 8 } })
useSensor(KeyboardSensor, { coordinateGetter: sortableKeyboardCoordinates })
```

- Мышь: перетаскивание начинается после сдвига на 6 px — клик по кнопкам
  карточки работает как клик.
- Палец: нужно задержать 200 мс. Иначе любой свайп по списку начинал бы
  перетаскивание и список нельзя было бы прокрутить.
- Клавиатура: Tab до карточки → Пробел → стрелки → Пробел. Кнопки внутри
  карточки гасят `keydown` (`stopPropagation`), чтобы Пробел на кнопке
  нажимал кнопку, а не поднимал карточку.

## Доступность

dnd-kit сам ставит карточкам `role="button"`, `aria-describedby` с
инструкцией и озвучивает действия через скрытую live-область. По
умолчанию — по-английски, поэтому в `Board.tsx` переданы русские
`announcements` и `screenReaderInstructions`.

## Почему копия в `DragOverlay`

Если двигать саму карточку, при переносе в другой список она
размонтируется и пересоздаётся — перетаскивание бы обрывалось. Overlay
живёт отдельно от списков, а на месте карточки остаётся полупрозрачный
«след» (`data-dragging`).
