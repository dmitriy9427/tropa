# 01. Архитектура

## Папки

```
src/
  app/                    маршруты Next.js (App Router)
    layout.tsx            общая обёртка всех страниц: <html>, шрифты, шапка
    page.tsx              главная «/»
    trip/page.tsx         планировщик «/trip/?id=…»
    icon.svg              фавиконка (Next подключает сам по имени файла)
  components/             компоненты главной и общие
    planner/              всё, что внутри планировщика
  lib/                    логика без React: даты, гео, API, ссылка «поделиться»
  store/                  хранилища Zustand (поездки, уведомления)
  styles/globals.scss     токены темы и общие классы
scripts/                  вспомогательные скрипты сборки
docs/                     эта документация
```

Правило: **в `lib/` нет React.** Там чистые функции — их легко тестировать
(`*.test.ts` лежат рядом). Компоненты только вызывают их.

## Модель данных

Вся поездка — один объект `Trip` (`src/lib/types.ts`):

```ts
Trip {
  city      — город: название, координаты, часовой пояс
  places    — словарь всех мест поездки по id
  ideaIds   — id мест, которые ещё не разложены по дням
  days[]    — { date: '2026-10-13', placeIds: [...] }
}
```

Места хранятся один раз в `places`, а дни и «Идеи» держат только списки id.
Поэтому перенос места между днями — это перестановка строки в двух массивах,
а не копирование объекта, и у одного места не бывает двух разных версий.

Даты — строки `YYYY-MM-DD`, а не `Date`. «13 октября» — это день в календаре,
а не момент времени: `new Date('2026-10-13')` в Нью-Йорке оказался бы 12-м.
Подробности в `src/lib/dates.ts`.

## Путь данных: что происходит при перетаскивании

1. Пользователь отпускает карточку → dnd-kit вызывает `onDragEnd` в `Board.tsx`.
2. `Board` вызывает действие хранилища `movePlace(tripId, placeId, куда, позиция)`.
3. Хранилище (`store/trips.ts`) применяет **чистую функцию** `movePlace` из
   `lib/trip.ts` и кладёт новый объект поездки в состояние.
4. `persist` сохраняет состояние в localStorage.
5. Все компоненты, подписанные на эту поездку, перерисовываются: список,
   статистика дня (километры, время), карта (линии и номера меток).

Ни один компонент не меняет данные напрямую — только через действия
хранилища. Поэтому изменения предсказуемы, а логику проверяют тесты
`lib/trip.test.ts` без браузера.

## Внешние сервисы

| Что | Откуда | Ключ |
| --- | --- | --- |
| Поиск городов | Open-Meteo Geocoding | не нужен |
| Поиск мест | Photon (komoot) | не нужен |
| Подборка достопримечательностей | Wikidata SPARQL | не нужен |
| Кафе | Overpass (OpenStreetMap) | не нужен |
| Погода | Open-Meteo Forecast | не нужен |
| Фото | Wikimedia Commons | не нужен |
| Подложка карты | OpenFreeMap | не нужен |

Все сервисы бесплатные и разрешают запросы прямо из браузера (CORS),
поэтому собственный сервер не нужен — сайт целиком статический.
