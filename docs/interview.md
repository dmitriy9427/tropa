# Шпаргалка к собеседованию

Вопросы, которые могут задать по проекту, и ответы на его примере. Сначала
прочитай главы 01–05 — здесь короткие формулировки, а подробности там.

## Next.js

**Чем серверный компонент отличается от клиентского?**
Серверный выполняется на сервере (у нас — при сборке), в браузер уходит
только HTML, его код не попадает в бандл; хуки и обработчики событий в нём
нельзя. Клиентский помечен `'use client'`, тоже рендерится в HTML, но его
код загружается в браузер и гидратируется. В «Тропе» страницы и шапка —
серверные, форма, список поездок и весь планировщик — клиентские.

**Зачем вообще серверные компоненты, если сайт статический?**
Меньше JS в браузере. Пример — `Topo.tsx`: линии рельефа на главной
считаются при сборке, пользователь получает готовый SVG, а генератор не
скачивает.

**Что такое гидратация и какие проблемы с ней были?**
React в браузере «привязывается» к HTML, который пришёл с сервера, и
ожидает, что первый рендер совпадёт с ним. Проблемы — всё, чего нет при
сборке: localStorage (поездки), текущая дата, тема. Решения: `skipHydration`
у Zustand persist и заглушка до загрузки, форма только после гидратации,
инлайн-скрипт темы в `<head>` + `suppressHydrationWarning`,
`useSyncExternalStore` с серверным значением.

**Почему `/trip/?id=…`, а не `/trip/[id]`?**
Статический экспорт собирает все страницы заранее, а id поездок появляются
у пользователя. Динамический сегмент потребовал бы `generateStaticParams`
со списком всех id.

**Зачем `Suspense` вокруг планировщика?**
`useSearchParams` при статической сборке не знает адреса. Всё внутри
ближайшего `Suspense` рендерится в браузере, а в HTML уходит `fallback`.
Без `Suspense` сборка выдаёт ошибку.

**Что делает `next/dynamic` с `ssr: false`?**
Грузит компонент отдельным чанком и только в браузере. Карта MapLibre
обращается к `window` и WebGL — при сборке их нет; заодно тяжёлая
библиотека не задерживает список.

**Что даёт `next/font`?**
Шрифт скачивается при сборке и раздаётся с того же домена — нет запроса к
Google и сдвига вёрстки при подгрузке; подключается через CSS-переменную.

**Чем ограничен статический экспорт?**
Нет серверного рендера по запросу, Server Actions, Route Handlers,
middleware, оптимизации `next/image`, динамических маршрутов без
`generateStaticParams`. Для этого проекта ничего из этого не нужно: данные
пользователя — в браузере, внешние данные — открытые API с CORS.

**Что поменялось бы, если бы появился бэкенд (аккаунты, общий доступ)?**
Убрать `output: 'export'` и хостить на Vercel/своём Node; поездки хранить в
БД; чтение — в серверных компонентах, изменения — через Server Actions или
Route Handlers; ссылка «поделиться» стала бы короткой `/trip/abc123`.

## React и состояние

**Почему Zustand?**
Хук без провайдера, подписка через селектор (перерисовывается только то,
что изменилось), `persist` в localStorage из коробки. Context перерисовывал
бы всех потребителей, Redux для такого объёма избыточен.

**Где логика: в компонентах или в хранилище?**
Ни там, ни там — в чистых функциях `lib/trip.ts` (`movePlace`, `removeDay`…).
Хранилище только вызывает их. Поэтому вся логика раскладки покрыта
тестами без React.

**Зачем TanStack Query, если можно `useEffect` + `fetch`?**
Кеш по ключу (погода запрашивается один раз на все дни), отмена старых
запросов при вводе, повторы, состояния загрузки и ошибки, `refetch`. Своими
руками это сотни строк и гонки запросов.

**Как устроено «поделиться» без сервера?**
Поездка сжимается в адрес: компактные массивы → JSON → `lz-string`. У
получателя раскодируется с новыми id и сохраняется; хеш ссылки защищает от
дублей.

**Как сделано перетаскивание между списками?**
dnd-kit: один `DndContext`, у каждого дня свой `SortableContext`.
`onDragOver` переносит карточку в другой список сразу (соседи
раздвигаются), `onDragEnd` фиксирует порядок, `onDragCancel` откатывает к
снимку. Датчики: мышь с порогом 6 px, палец с задержкой 200 мс, клавиатура.

**Что с доступностью?**
Перетаскивание с клавиатуры и озвучка на русском; поле города — паттерн
WAI-ARIA combobox (`aria-activedescendant`, стрелки, Enter, Esc); вкладки —
`role="tablist"`; переключатель темы — `role="switch"`; уведомления —
`role="status"`; `prefers-reduced-motion` отключает анимации.

## Карта

**Как подружить React и MapLibre?**
Карта создаётся один раз в `useEffect` и хранится в `useRef`; остальные
эффекты синхронизируют её с пропсами; в очистке `map.remove()`.

**Как сделана анимация маршрута?**
`line-gradient` со ступенькой по `line-progress`, позиция ступеньки растёт
в `requestAnimationFrame`. Для `line-progress` у источника включён
`lineMetrics`.

**Какие были баги?**
Метка «уезжала» при наведении: MapLibre позиционирует её через `transform`,
а CSS `scale` на том же элементе масштабировал и смещение — оформление
перенесено во вложенный `span`. И воркер MapLibre 6, который сборщик не
копировал, — копируем скриптом в `public/`.

- e2e-тесты на Playwright (перетаскивание, ссылка «поделиться»).
